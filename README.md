# MMBN SFX

This repo is a KDE Plasma sound theme using sounds effects from the popular GBA game series, Megaman Battle Network. 

# Setup:

## Nix(OS):
The default overlay provided by this package exposes the `pkgs.mmbn-sfx` package, which can be added to home-manager or any other NixOS configuration.

## Otherwise:
Clone this repository to the following directory: `/home/$USER/.local/share/sounds`

# To use:
1. Open KDE System Settings.
2. Navigate to **Colors & Themes > System Sounds**.
3. Select the `Megaman Battle Network` sound pack and click the `Apply` button.
